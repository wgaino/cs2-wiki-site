## 🚀 CS2 Wiki - Site de Exemplo

Este projeto é um site de exemplo no formato **wiki** (enciclopédia colaborativa) focado no jogo **Counter-Strike 2 (CS2)**. Ele foi desenvolvido como um exercício prático durante uma imersão de aprendizado da **Alura**.

---

### 🌟 Visão Geral

O CS2 Wiki serve como uma demonstração das habilidades e conceitos aprendidos, aplicando a temática do popular jogo CS2 para criar um conteúdo envolvente. O objetivo principal foi consolidar conhecimentos em desenvolvimento web através de um projeto com escopo definido.

---

### ✨ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **HTML:** Para a estruturação e conteúdo das páginas.
* **CSS:** Para a estilização, layout e design responsivo.
* **JavaScript Para buscar elementos no data.json, com funções que inserem <articles> no HTML, e fazem a busca de dados
* **Gemini** e também **Google AI Studio** Para preencher a base de dados utilizando inteligencia artificial
* **Node.js** para gerar o prompt inteligente para busca de dados, utilizando alguns codigos de node no prompt de comando (ainda estou me familiarizando com o node).

### 💻 Como Visualizar o Projeto

Para ver este projeto em funcionamento, você tem duas opções:

1.  **Acessar a Página Publicada:**
    O site está publicado no GitHub Pages. Você pode acessá-lo diretamente através do link:
    * (https://wgaino.github.io/cs2-wiki-site/) 

2.  **Executar Localmente:**
    * Faça um **clone** deste repositório para o seu computador:
        ```bash
        git clone [https://github.com/wgaino/cs2-wiki-site.git](https://github.com/wgaino/cs2-wiki-site.git)
        ```
    * Navegue até o diretório clonado:
        ```bash
        cd cs2-wiki-site
        ```
    * Abra o arquivo `index.html` em seu navegador de preferência.

### 🎓 Aprendizado e Exercício

Este projeto foi realizado como parte de uma **Imersão da Alura**. Durante o desenvolvimento, foram praticados conceitos essenciais como:

* **Estruturação Semântica** de documentos HTML.
* **Criação de Layouts** com CSS (incluindo *Flexbox* ou *Grid*).
* **Estilização** de componentes e elementos.
* **Responsividade** (garantindo que o site funcione bem em diferentes tamanhos de tela).
